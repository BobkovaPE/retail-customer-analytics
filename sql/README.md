# План SQL

- `01_orders.sql` создан: сборка одной строки на заказ.
- `02_monthly_metrics.sql` создан: месячные продажи, заказы, средний чек, изменения к предыдущему месяцу и покрытие CustomerID.
- `03_customer_metrics.sql` создан: клиентские агрегации, первая/последняя покупка, частота и сумма.
- `04_customer_monthly.sql` создан: впервые и ранее наблюдаемые клиенты и их вклад в месячные известные продажи.
- `05_cohort_activity.sql` создан: число клиентов когорты с покупкой в каждом месяце её возраста.
- `06_repeat_purchase_30d.sql` создан: полный срок наблюдения и следующий заказ за 30 дней; параметр cutoff — исключённая правая граница окна.

Запрос 01 выполняется ноутбуком подготовки. Запросы 02–06 читает и выполняет аналитический ноутбук через соединение только для чтения. Проверки SQL/pandas доступны в ноутбуке.

Этап 5: `07_day14_experiment_baseline.sql` — исторический аналог отбора через 14 суток, число счетов до точки входа, полнота окна и покупка в последующие 30 суток. Параметр cutoff. Выполняется ноутбуком 03 через read-only соединение; все клиенты сверены с pandas.
