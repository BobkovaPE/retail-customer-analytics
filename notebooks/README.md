# Ноутбуки

1. `01_data_preparation.ipynb`: 11 кодовых ячеек — загрузка, профилирование, правила отбора, аудит, SQLite и сверки
2. `02_customer_analytics.ipynb`: 19 кодовых ячеек — SQL/KPI, когорты, RFM, концентрация и восемь графиков
3. `03_experiment_design.ipynb`: 6 кодовых ячеек — исторический аналог отбора на 14-е сутки, независимая pandas-сверка, интервал и мощность

Порядок выполнения 01 → 02 → 03; пути относительно корня проекта. Для полного воспроизведения нужен проект вместе с SQL, а не отдельный ноутбук. Команда: `python scripts/run_pipeline.py`
